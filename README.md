# E-Commerce Website

Group Capstone Project built with React, Tailwind CSS, React Router, and Redux Toolkit.

## Features

- Responsive Home page
- Product search and filtering
- Reusable ProductCard and ProductList components
- Product detail page
- Redux-powered shopping cart
- Cart persistence with localStorage
- Checkout forms with validation
- Order summary
- Order success page
- Responsive mobile navigation

## Tech Stack

- React
- Tailwind CSS
- React Router
- Redux Toolkit
- Vite
